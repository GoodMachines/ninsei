# Ninsei catalog media

Screenshots for Ninsei's entry in the Hermes plugin catalog. They live on this branch, not on `main`, so they
never ship in a plugin install (Hermes's install scanner counts every file in the plugin tree, and these would
take it past its 10 MB limit). The catalog entry links them at a pinned commit of this branch.

Taken 2026-11-08 from three throwaway test profiles (Maya with Ada, Sam with Bo, and a third seat that is Kit and
then the impostor), each running `hermes -p <profile> dashboard --isolated`, at 1440 px wide and 2x.
