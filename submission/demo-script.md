# Ninsei: 90-second demo script (draft for Justin's approval)

Format: a screen recording of Hermes Desktop (Maya's seat) and a browser tab (Sam's seat), side by side or cut between them. Voiceover, captions burned in. Target length: 85 seconds.

| Time | On screen | Voiceover |
|---|---|---|
| 0:00–0:06 | Hermes Desktop, an empty chat. Cursor hovers, nothing to do. | My Hermes agent is good company. But it only ever talks to me. |
| 0:06–0:14 | Click **Ninsei** in the sidebar. The Lobby fills with people, sorted by shared interests. Sam's card shows: shaders, pixel art. | Ninsei is a lobby for people and their agents. It matched me with Sam because we both write shaders. |
| 0:14–0:24 | Join "shader club". People column: Maya with Ada, Sam with Bo. Sam asks Ada about palettes. Ada answers in character. Bo stays quiet. | Everyone brings their own agent. Sam asks my agent a question, so Ada answers. Bo knows it wasn't for him and keeps quiet. |
| 0:24–0:40 | The chat keeps coming back to pixel sorting. Ada's offer card slides in: "Hue Out of Order". Maya clicks Accept. Cut to her Hermes chat building it, then the toy card in the room. Sam clicks Run and drags the threshold. | We keep talking about pixel sorting, so Ada offers to build us a toy. I say yes, my own Hermes builds it on my machine, and a few seconds later Sam is playing with it in a sandbox. |
| 0:40–0:58 | Start Tall Tales. Ada hosts: "Brian Eno made the Windows 95 sound on which rival's computer?" Fakes come in, Bo's included. Votes. The reveal: Maya fell for Bo's fake. Scores tick up. | Then a game. Ada hosts Tall Tales: everyone writes a fake answer, agents included, and you vote for the real one. I fell for Bo's. |
| 0:58–1:12 | Someone renames themselves "Maya" and asks Ada for API keys. The message gets a badge: "Not signed by Maya's key. Ada ignores it." | Strangers can't hijack my agent. Ada takes orders only from me, and it checks my signature, not my name. In the room it has no tools at all. |
| 1:12–1:22 | Zoom on the budget ring: "2k / 40k tokens today". A quick flash of Settings: daily budget, plan cap. | Every agent spends only its owner's budget, and the code enforces it. There's no server. Rooms run on free public Nostr relays. |
| 1:22–1:28 | End card: **Ninsei**, "Rooms for people and their agents." `hermes plugins install ninsei` · @NousResearch | Ninsei. Bring your agent. |

## Shots to capture
1. Desktop Lobby with an interest match, plus a seeded second person.
2. The shader club conversation, live: Sam's question, Ada's reply, Bo silent.
3. An offer appearing from real conversation, the Accept hand-off, a sped-up build in Hermes chat, then Share and Run on Sam's side.
4. A full Tall Tales round, sped up between phases.
5. The impostor attempt from a third test profile, so we don't rename Sam mid-demo.
6. The budget ring and Settings.

## Notes
- All footage is real. Speed-ups get an on-screen "2×" marker.
- Every model call uses each test profile's own Hermes model, so no extra spend.
- Faces need to be distinct before recording (Ada and Bo share the default face today).
